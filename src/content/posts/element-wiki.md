# introduction

Element Wiki is a self-hosted knowledge base for teams and individuals, named after the Vue-based Element Plus UI toolkit that powers its frontend. Built with a Go backend, it runs as a single binary with SQLite out of the box (optional PostgreSQL) and embedded Bleve full-text search, with OIDC SSO sign-in. It offers an infinitely nestable document tree, immutable linear versioning, auto-save drafts, concurrent edit conflict detection, a recycle bin, and fine-grained permissions.
